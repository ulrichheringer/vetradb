# M03 locked dependency review

`dependencies.json` pins exact direct versions/features and every crates.io transitive source/version/checksum/license/MSRV. The workspace gate rejects a changed direct configuration or transitive lockfile inventory. Original bootstrap was std-only; M03 introduces bounded parser/value/serialization utilities, never an authoritative external storage engine or networking runtime.

| Direct utility | Choice and reviewed source | Rationale, alternatives and removal |
| --- | --- | --- |
| sqlparser 0.53.0, std/visitor only | Apache-2.0; [official source](https://github.com/apache/datafusion-sqlparser-rs); source/package APIs read locally, no parser runtime I/O | Explicit PostgreSQL AST, token locations and bounded recursion; hand-written broad grammar would multiply correctness risk. Replacing it requires the existing golden/parser/binder corpus; unsupported syntax remains execution-gated |
| serde 1.0.228 derive; serde_json 1.0.145 arbitrary_precision | MIT/Apache-2.0; [serde](https://github.com/serde-rs/serde), [JSON](https://github.com/serde-rs/json); derives and exact JSON numbers, default depth checks | Tagged bounded internal codecs avoid lossy casts and unversioned ad hoc metadata. Removal requires codec-v1 decoding/migration, never simply changing on-disk bytes |
| bigdecimal 0.4.8 | MIT/Apache-2.0; [official source](https://github.com/akubera/bigdecimal-rs), reviewed numeric/build-script APIs | Arbitrary precision exact coefficients; fixed-width decimal cannot cover declared digits. Parsing/scale/resource limits are checked; quotient rounding uses explicit exact integer arithmetic and fixed SQL policy rather than default library division precision |
| chrono 0.4.42, std only; clock/default features disabled | MIT/Apache-2.0; [official source](https://github.com/chronotope/chrono) | Reviewed date/time parsing/checked conversion; no ambient wall clock or timezone provider is imported. Time inputs are injected into sessions and persisted once. A replacement must preserve value/SQL fixtures |

The complete transitive inventory is machine-readable, including proc macros (`serde_derive`, `sqlparser_derive`, `syn`, `quote`, `proc-macro2`) and numeric/format utilities. Permissive MIT/Apache options are selected where offered; `unicode-ident` also includes Unicode-3.0 attribution. Registry manifest licenses/MSRVs were inspected; unknown/custom/copyleft dependencies are not introduced. Upstream release histories are available from the linked primary repositories; these are deliberately fixed known API releases rather than floating updates. Pinning is not a claim of future maintenance or security support.

OSV's primary query API checked all **21 locked external packages** at their exact versions on 2026-10-04/05 UTC: **no returned advisories**. This is a timestamped database result, not proof of absence of vulnerabilities. MSRV 1.85 and pinned stable 1.97.1 plus the four native CI targets are the compatibility gates; metadata MSRV is recorded but never substitutes for compilation.

Proc macros and the num-traits/autocfg/bigdecimal build scripts run as compiler tools; their registry source was read and they do not own storage/network behavior. Workspace code still forbids unsafe; external libraries can contain audited implementation unsafe and are not covered by that lint. Their bounded usage, unchanged lossless codec fixtures, exact source checksums and native target gates are the acceptance boundary. Broader recurring advisories/license automation and published release SBOM remain M09 work.
